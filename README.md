# Calculadora de Notas

Programa de consola en Python que permite al usuario ingresar y registrar sus notas académicas de forma interactiva.

---

## Descripción

Esta herramienta solicita al usuario la cantidad de notas obtenidas durante su proceso de aprendizaje y luego las recibe una por una mediante entrada estándar. Está diseñada para ser simple, directa y reutilizable.

---

## Requisitos

- Python 3.x

No requiere librerías externas.

---

## Uso

1. Clona o descarga el archivo del programa.
2. Ejecuta el script desde la terminal:

```bash
python calculadora_notas.py
```

3. Sigue las instrucciones en pantalla:
   - Ingresa la **cantidad de notas** que deseas registrar.
   - Ingresa **cada nota** cuando el programa te lo solicite.

---

## Ejemplo de ejecución

```
############################
### CALCULADORA DE NOTAS ###
############################
ingrese la cantidad de notas que fueron tomadas en tu proceso de aprendizaje: 3
ingrese una nota: 85
ingrese una nota: 90
ingrese una nota: 78
```
